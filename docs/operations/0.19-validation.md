## Docker pull troubleshooting

Use the exact lowercase image `ghcr.io/gaspareduard/omada-mcp:latest`. If anonymous pulls fail, compare the error's registry/image/tag and check whether an expired cached GHCR login or a network proxy is involved. Test from a clean Docker credential configuration before changing package visibility. Record the Docker version, platform, full nonsecret error, requested tag and timestamp. Successful manifest access alone does not prove a full image pull.
